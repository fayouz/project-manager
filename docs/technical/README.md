# Documentation Technique

Ce répertoire contient la documentation technique de référence de l'application **Project Manager**.

---

## Sommaire des Guides

- [Connecteurs d'Intégration](connectors.md) : Architecture des connecteurs tiers (Jenkins, Gitea, SonarQube, Mantis, Nexus), résolution centralisée des proxys réseau (`ProxyResolver`), gestion polymorphique des paramètres et guide d'ajout d'un nouveau connecteur.
- [Guide utilisateur (`/guide`) — Documentation Nuxt Content](frontend-guide-docs.md) : Section de documentation applicative construite avec Nuxt Content v3 et Nuxt UI v4, sur le modèle du template `nuxt-ui-templates/docs`.
- [Page Changelog (`/changelog`)](frontend-changelog.md) : Timeline des évolutions de l'application construite avec `UChangelogVersions`/`UChangelogVersion` (Nuxt UI v4.11) et du contenu Markdown local (Nuxt Content), sur le modèle du template `nuxt-ui-templates/changelog`.
