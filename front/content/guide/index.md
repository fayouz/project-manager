## Bienvenue

**Project Manager** est une plateforme qui centralise la gestion de vos **organisations**, **projets**, **équipes** et **serveurs de déploiement**, connectée à une API Platform (Symfony / Hydra) via un frontend Nuxt 4 + Nuxt UI v4.

Ce guide vous accompagne pour :

- comprendre la structure du projet (`front/`, `api/`),
- démarrer rapidement en local ou via Docker,
- découvrir les concepts clés : organisations, projets, serveurs, intégrations,
- personnaliser et étendre l'application (génération de CRUD, thèmes, navigation).

Cette documentation est écrite avec **Nuxt Content** et suit la même structure que le [template officiel `nuxt-ui-templates/docs`](https://github.com/nuxt-ui-templates/docs).

## Prochaine étape

Rendez-vous sur la page [Démarrage rapide](/guide/getting-started) pour lancer l'application.
