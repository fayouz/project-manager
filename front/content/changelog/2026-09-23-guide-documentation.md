Project Manager dispose désormais d'une section de documentation intégrée accessible sur [`/guide`](/guide), construite avec **Nuxt Content** et les composants de contenu de **Nuxt UI v4**.

- Navigation générée automatiquement depuis l'arborescence des pages.
- Recherche full-text (`Cmd+K`).
- Sommaire et navigation "précédent / suivant" sur chaque page.
- Premiers guides disponibles : démarrage rapide, navigation & structure, générateur de client `NuxtUi4Generator`.
